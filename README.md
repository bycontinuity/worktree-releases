# Worktree desktop releases

Official Worktree desktop downloads, update metadata, and release notes.

Download available builds from [Releases](https://github.com/bycontinuity/worktree-releases/releases).

Worktree is currently alpha software. Windows builds are unsigned and may show a publisher warning. Linux builds are AppImages. macOS builds are published only after Developer ID signing and Apple notarization.

The original internal `0.1.0-alpha.1` build requires one manual upgrade to an update-enabled release. Update-enabled builds check this repository for new alpha releases and let you choose when to restart and install.

Each platform includes SHA-256 checksums and a build manifest. Keep projects backed up before using prerelease software.

This repository contains distribution artifacts only. Application source is maintained separately in a private repository. Worktree is built on OpenCode; upstream license notices and third-party attributions remain applicable.
